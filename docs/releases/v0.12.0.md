## Overview

Version **0.12.0** establishes the canonical **Enterprise Security Console Architecture** for the Enterprise Agent Security Platform.

This architectural milestone transforms the platform's user interface from a static database inventory representation into a workflow-centric, evidence-first **Enterprise Security Operations Console** tailored for SOC analysts, security engineers, and governance officers.

The release preserves all core platform invariants: Zero Trust architecture, treating LLMs as untrusted intent parsers, deterministic security enforcement outside the model, and the backend as the sole source of truth.

---

## Highlights

- **ADR-022 Accepted:** `ADR-022: Enterprise Security Console Evolution` formally accepted as the governing frontend architecture for `v0.12.0` through `v1.0.0`.
- **Workflow-Centric Navigation:** 3-mode primary navigation structure (`MONITOR`, `INVESTIGATE`, `GOVERN`) comprising 9 canonical routes.
- **Work-Oriented Command Center:** Zone 1 (Action Required Work Queue) and Zone 2 (Operational Awareness).
- **Session Investigation Workspace:** Multi-panel forensic environment (`/sessions/:id`) anchored by a Focal Behavioral Timeline.
- **Canonical Investigation Graph:** First-class architectural contract governing causal entity chains (`Agent → Session → ToolInvocation → PolicyEvaluation → BehavioralEvent → Finding → RiskAssessment → EnforcementDecision → AuditEvent → Case`).
- **Audited Operator Write Commands:** Governance write operations (session approvals/rejections, analyst annotations) submitted as backend-validated commands.
