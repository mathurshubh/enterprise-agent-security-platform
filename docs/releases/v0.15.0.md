## Overview

Version **0.15.0** introduces **Runtime Capability Discovery**, establishing a passive aggregation boundary for discovering active platform capabilities.

---

## Highlights

- **Passive Capability Discovery (PR #75):** Added `CapabilityService` and typed `PlatformCapabilities` domain model to dynamically aggregate registered tool capabilities, content detection rules, and behavioral detection rules without mutating runtime state.
- **Shared Registry Integration:** Injected shared `ToolRegistry`, `DetectionRegistry`, and `DetectionService` across runtime and capability discovery boundaries.
- **Scenario Capability Matrix Documentation:** Created `docs/security/scenario-capability-matrix.md` mapping security validation scenarios to underlying platform capabilities.
