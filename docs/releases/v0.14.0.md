## Overview

Version **0.14.0** establishes the **Enterprise Scenario Library & Validation Framework** for static security benchmarking and regression testing.

---

## Highlights

- **Structured YAML Scenario Library (PR #72):** Migrated security scenarios from inline JSON to structured YAML specifications across 9 security categories (`authorization`, `benign_baselines`, `data_exfiltration`, `prompt_injection`, `provider_failures`, `sensitive_file_access`, `session_behavior`, `tool_abuse`, `workflow_security`).
- **Scenario API (`/api/scenarios`):** Added `GET /api/scenarios`, `GET /api/scenarios/{id}`, and `POST /api/scenarios/{id}/execute` endpoints.
- **Scenario Runner Integration:** Integrated `ScenarioRunnerService` with dual-mode runtime execution and security assertion grading.
- **Scenarios UI Console:** Added Scenario Detail Panel, Scenario Table, and execution trigger UI in the Enterprise Security Console (`/scenarios`).
